# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-07

### Added

- **Chat interface** — streaming chat with Claude Code CLI, multi-tab sessions, real-time output
- **Session management** — list, stop, and resume Claude Code sessions
- **Kanban board** — task columns with drag-style management
- **Agent watch** — monitor subagent activity across sessions
- **Capabilities discovery** — detect MCP servers, plugins, skills, and tools
- **Cron job scheduling** — schedule recurring Claude Code prompts with node-cron
- **Analytics dashboard** — token usage, cost tracking, model breakdown with Recharts charts
- **Data export** — export sessions, analytics, and cron data as JSON/CSV
- **Artifact gallery** — browse, tag, pin, and preview Claude Artifacts
- **Thinking block visualization** — collapsible thinking blocks in assistant messages
- **Tool use visualization** — expandable inline cards showing tool name, input, and result
- **Desktop notifications** — browser Notification API for session and cron job completion
- **Search** — full-text search across sessions and chat history
- **Settings UI** — theme (light/dark/system), LAN access, PIN code authentication, notification toggle
- **WebSocket streaming** — real-time bidirectional communication for chat and events
- **PIN code authentication** — optional security for LAN access
