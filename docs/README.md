# Docs

This directory contains planning and design documents used during Konduktor's development.

## For Users

- **[Getting Started](getting-started.md)** — installation, setup, and feature walkthrough

## Internal Planning Docs

The files in `plans/` and `grilling/` are internal development artifacts written in Indonesian during the planning and design process. They are kept for transparency and historical reference, but are not intended as user-facing documentation.

- `plans/` — implementation plans for each development phase
- `grilling/` — requirement validation sessions
- `research/` — competitive analysis and research notes
